拉丁爵士

克拉维与蒙图诺托住爵士即兴，舞池与独奏同台。

爵士拉丁爵士古巴打击乐

现代当代克拉维拉丁打击组

拉丁爵士把古巴与巴西的舞曲节奏带进爵士乐队，让 clave、montuno 与即兴独奏共用一张谱。

起源与年代

1940 年代，纽约的 Machito 与 Mario Bauzá 把非洲古巴节奏放进大乐队，1943 年的《Tanga》常被看作早期样本。1947 年 Dizzy Gillespie 与 Chano Pozo 合作《Manteca》，把 conga 与爵士铜管推到前台。1950 至 60 年代，Tito Puente、Cal Tjader、Chico O'Farrill 与 Eddie Palmieri 扩展了 mambo、cha-cha 与拉丁爵士；巴西一侧则由 bossa nova 与 Stan Getz、Jobim 的合作为人所知。

听辨特征

先找 clave：2–3 或 3–2 的五击循环决定重音落在哪。贝斯常走 tumbao，钢琴右手弹 montuno，铜管用短 riff 回应；conga、timbales、bongos 与 claves 把时间切成多层。爵士和声与独奏仍在，但鼓组的角色从「伴奏」变成「共同作曲」。

代表人物

Machito 与 Mario Bauzá 建立纽约古巴爵士的编制，Dizzy Gillespie 与 Chano Pozo 把 conga 带进爵士，Tito Puente 让 timbales 成为主角，Cal Tjader 用颤音琴把拉丁爵士带向更柔的音色。Eddie Palmieri、Ray Barretto 与 Poncho Sanchez 把萨尔萨与爵士的连接延续到后来。

谱系

上承 son、mambo、rumba、cha-cha 与巴西 samba，下接萨尔萨、songo、拉丁融合与平滑拉丁爵士；它同时反向影响主流爵士的节奏组。

常见误解

拉丁爵士不等于萨尔萨，萨尔萨以舞曲与歌曲为主，拉丁爵士更强调爵士和声与即兴。它也不只是「爵士加康加鼓」，clave 与 montuno 的组织方式才是骨架。把它和 bossa nova 混为一谈，会忽略古巴与巴西两条不同的节奏传统。
